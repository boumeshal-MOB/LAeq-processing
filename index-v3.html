Catch-up missing periods explained: when enabled, every event-driven or custom execution looks at the last stored result for each generated variable, then calculates every complete missing period up to the latest available data. It prevents gaps after downtime or missed ingestion events, creates 15-min/1h/10h results that were missed, and should write with upsert keys to avoid duplicates. It never creates future or incomplete periods.
Implementation handoff: React/Next.js for forms and administration; Node for configuration, event handling, queue/debounce, fallback scheduling and missing-boundary detection; Python Lambda for energetic LAeq calculation and database upsert.
