Catch-up missing periods: every run reads the last stored end timestamp for each generated variable and creates all complete missing periods up to the current data watermark. Example: a 15-min rolling output every 1 min can be calculated every 15 min; one run then creates up to 15 missing rolling results. Upsert keys prevent duplicates. Future or incomplete periods are never generated.
