Scientific rule: LAeq = 10 × log10(mean(10^(Li/10))). A simple arithmetic average of decibel values must not be used.
Fixed: non-overlapping calendar-aligned blocks, e.g. 10:00–10:15. Rolling: a new result at each output step using the previous complete period.
Duration represented by each LAeq result. It is the historical window used in the energetic calculation.
Used only when Custom is selected. Example: 300 seconds for LAeq,5min.
Time between two results. In fixed mode it equals the LAeq period. In rolling mode it can be shorter, e.g. a 15-minute window every 60 seconds.
Timestamp assigned to the generated BTM value. Period end is recommended for acoustic indicators.

Period calculations use all valid measurements inside the configured local-time interval. For Lden, +5 dB evening and +10 dB night penalties are applied only to the combined Lden formula, never to stored raw or period LAeq values.
Percentage of the requested period that must have elapsed before finalization. At 100%, BTM waits for the end of the period. A tolerance of one source interval is used for file exports ending just before a clean boundary, such as 10:59:59 for 11:00.
Valid numeric samples divided by the expected sample count based on source resolution. Example: 12 valid one-minute values in a 15-minute period = 80%. Empty, null, NaN and non-numeric values are excluded.
Production BTM may wait for late files or recalculate previously generated periods when delayed measurements arrive.
Temporal completion and valid-data coverage are different: the first tells us whether the period is closed; the second tells us whether enough usable measurements exist inside it.
With the one-hour Micromate example, only short-term 15-minute outputs are expected because day/night periods are not complete.
Example generated names: Noise_LAeq_15min, Noise_Lnight or Noise_Lden.
Production BTM must be idempotent so repeated or overlapping files do not create duplicate results.
Each stored result should include timestamp, period start/end, represented duration, sample count, expected count, valid-data coverage, period type, source variable ID and processing ID.
