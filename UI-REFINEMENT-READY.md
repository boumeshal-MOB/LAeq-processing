# LAeq V3 UI refinement

This follow-up keeps the existing LAeq calculation logic and refines the mockup for production handoff.

- Compact table for multiple LAeq outputs.
- Scheduler tab includes selected and recommended execution frequency.
- Catch-up behaviour is explained with the last stored boundary logic.
- Manual run is the last tab and visually highlighted.
- Administration starts with a list of several processings; full details appear only after Edit.
- Existing Micromate/CUBE parsing, fixed/rolling/calendar calculations, coverage and catch-up logic remain available.
